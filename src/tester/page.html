Adblock rule-type tester

One probe per rule type, judged from inside this page. It reports what your blocker actually did, whoever the blocker is — this project's proxy, uBlock Origin, or nothing. Turn the proxy off and the results describe your extension instead.

Setup. The No setup needed section works as-is. Every other section needs rules aimed at this page, and your blocker has to be given them. It only touches /test/a/ paths and this page's own classes, so no real site is affected.

In uBlock Origin — do it this way rather than subscribing, because uBO discards $replace, $urlskip and $uritransform from a list it does not trust, and it only trusts this box.

  1. Press
  2. Click the uBlock Origin icon in the toolbar, then the gears icon (⚙) in the popup. The dashboard opens in a new tab.
  3. Open the My filters tab along the top.
  4. Click in the big text box and paste, below anything already in there.
  5. Tick Trust my filters, above the box.
  6. Press Apply changes, top right.
  7. Come back here, reload this page, and press Run all tests.

If the copy button does not work (clipboard access needs a secure page), open in a tab and copy the text by hand.

In this project's dashboard, add that same URL as a blocklist. Re-fetch it after any change.

The list is written for the exact host you asked it from, so take it from the address you open the tester on — a copy made on localhost does nothing on a LAN address. Third-party tests use , which has to reach this same server or those tests mean nothing.

To test this project's proxy rather than an extension, the page has to reach you through the proxy. Browsers send loopback straight to the server and never to a proxy, so localhost and 127.0.0.1 cannot be used for that. Add a DNS rewrite of *.test to 127.0.0.1, then open this page at http://tester.test/test. Keep the port — the rewrite changes the address, not the port. Check the name is not in the proxy's excluded hosts. To test an extension instead, turn the proxy off — nothing here depends on it.
